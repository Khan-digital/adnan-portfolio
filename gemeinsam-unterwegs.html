Gemeinsam Unterwegs

A route-based carpooling experience designed to help drivers and passengers discover journeys they can share. My contribution connects UX/UI design with hands-on, AI-assisted web implementation, integration and testing.

The product challenge

People travelling along similar routes may be able to share a journey, but the product needs to collect enough structured information to understand who is travelling, where they are going, when they travel and whether their routes overlap.

The experience needs to make a multi-step survey approachable while capturing useful route, schedule, passenger and vehicle details.

Experience design

I worked on the survey experience and its supporting interface, balancing detailed data collection with a clear user journey.

Journey information

Starting point, destination, via locations, travel dates, times and journey frequency.

People and vehicles

Driver or passenger interest, vehicle and seat information, passenger composition and child-seat requirements.

Route interaction

Interactive map, address search, start and destination markers, route calculation and GPS route information.

Clear participation

Interest selection, cost contribution, ticket information, privacy confirmation and additional-journey submission.

AI-assisted implementation

I used ChatGPT and Claude as coding assistants to translate requirements into code, iterate on implementation and troubleshoot issues. I integrated the generated changes into the WordPress project and checked the behaviour in the actual website rather than treating generated code as finished by default.

  • Implemented and refined HTML, CSS and JavaScript in the WordPress page environment.
  • Worked on a custom PHP plugin and WordPress REST API submission flow for survey data and administration.
  • Integrated Leaflet maps and Leaflet Routing Machine, with address search through Nominatim and route calculation through OSRM.
  • Investigated data consistency between stored survey information, the admin interface and Excel exports.
  • Worked on route-overlap matching requirements using GPS route information, with attention to direction and false matches.

My workflow: understand the requirement → direct the AI assistant → integrate the code → test the real journey → debug and refine.

AI tools supported code generation and iteration. I remain responsible for checking the implementation and verifying the user-facing behaviour. This is practical AI-assisted development experience, not a claim of independently writing every line of code.

Validation and iteration

I test complete user journeys and edge cases rather than checking only whether a page loads. For this product, that includes:

  • Address search and route calculation for start, destination and via locations.
  • Form behaviour for driver and passenger selections, passenger composition and child-seat options.
  • Responsive layout and input behaviour across screen sizes.
  • Submission handling and the consistency of data shown in administration and exported files.
  • Reviewing GPS route information and matching rules to reduce misleading matches.

The work is iterative: identify the specific issue, inspect the relevant data or code, make a focused change, then retest the affected feature and surrounding functionality.

What this demonstrates

Gemeinsam Unterwegs is a practical example of how I work across the product lifecycle: connecting user needs and interface design with AI-assisted implementation, integration, debugging and product validation.

It has strengthened my ability to collaborate with AI coding tools while applying product judgement, checking edge cases and keeping the user experience at the centre of technical decisions.
